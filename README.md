# Let Us C – C Programming Solutions

This repository contains my solutions and practice programs from **Let Us C** by Yashavant Kanetkar.

I have solved problems covering topics such as:

* Basic C programming
* Operators and expressions
* Conditional statements
* Loops
* Functions
* Pointers
* Arrays
* Strings
* Structures
* Matrix problems
* Sorting and searching
* Pattern programs
* Problem-solving and logic building
* Small projects and practice programs

Some topics, such as **file handling and a few other advanced topics, are not included yet**.

The repository also contains different approaches and attempts for some problems, as I used them while learning and improving my understanding of C programming.

> **Note:** Some question statements have been reconstructed from my solutions, and some programs are learning attempts rather than fully optimized solutions.
